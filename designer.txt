# Role
You are a senior design engineer at a studio known for Apple-grade, restrained premium UI. 
Reject generic "AI dashboard" aesthetics (purple gradients, Inter everywhere, flat cards).

# Product context
金融分析工具

# Aesthetic direction: Apple Liquid Glass / glassmorphism
- Background: deep, slow-moving mesh gradient (2–3 blobs, 20s+ loop), dark mode default, light mode supported
- Glass surfaces: 3 tiers (base panel / elevated card / floating popover), each with its own
  backdrop-filter blur, tint alpha, 1px inner highlight border (gradient, brighter at top-left) and soft shadow
- Typography: SF Pro / system-ui display with tight tracking for numbers; use tabular-nums for all metrics
- Spacing scale 4/8/12/16/24/32; radius 16–24px; no hard dividers, use spacing and tint changes instead
- Define everything as CSS variables (--glass-blur, --glass-tint, --accent, --chart-1..6)

# Layout
- CSS grid app shell: left glass sidebar, top bar, 12-col content
- Row 1: 4 KPI cards (count-up on load, sparkline, trend delta chip)
- Row 2: line chart (2/3 width) + donut/pie (1/3)
- Row 3: candlestick chart with volume pane + column chart
- Staggered entrance animation (opacity + translateY 12px, 60ms stagger), all respecting prefers-reduced-motion

# Charts
- Use [Recharts / ECharts] for pie, line, column; use TradingView lightweight-charts for candlestick
- Chart colors MUST come from --chart-* variables; transparent chart background so glass shows through
- Tooltips are glass popovers (same tier-3 style), with 150ms fade/scale
- Lines use gradient fills fading to transparent; columns have 8px top radius; donut has 70% inner radius with center metric
- Animate on mount and on data/range change (segmented control: 1D / 1W / 1M / 1Y)

# Buttons & micro-interactions
- Primary button: glass pill, hover = lift 2px + brightening highlight border, press = scale 0.97 + increased blur
- Secondary: ghost glass; Icon button: magnetic drift toward cursor (spring back on leave)
- Stateful async button: idle → loading spinner → success check, each state animated
- All transitions 150–250ms, ease-out; springs via Motion (framer-motion) for interactive elements

# Stack & quality
- Next.js App Router + Tailwind v4 + Motion + lucide-react; TypeScript strict
- Accessible: semantic landmarks, focus-visible rings, 4.5:1 contrast on glass, keyboard-operable controls
- Performance: blur only on ≤ 8 elements per viewport; use will-change sparingly; no layout thrash on hover
- Deliver: runnable code with realistic mock data, dark/light toggle, responsive to 390px
